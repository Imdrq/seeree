# PRD — SiriAI for Windows

> 产品需求文档 | 版本 v1.0 | 2026-07-21

---

## 1. 产品概述

### 1.1 产品定位

**SiriAI for Windows** 是一款运行于 Windows 11 桌面的 AI 语音助手。它还原 iOS 27 Siri AI 标志性的**液态玻璃气泡**视觉风格，并以**灵动岛（Dynamic Island）**交互模式悬浮于桌面，提供自然语言对话、语音交互能力，底层接入 ChatGPT API。

### 1.2 目标用户

- Windows 11 桌面用户
- 偏好精美 UI / 高颜值工具的效率型用户
- 希望通过语音快速获取 AI 辅助的用户
- 喜欢 Siri 设计语言但使用 Windows 设备的用户

### 1.3 核心价值

| 维度 | 描述 |
|------|------|
| **视觉** | 还原 iOS 液态玻璃质感，提供差异化的桌面美学体验 |
| **交互** | Dynamic Island 胶囊形态，不打扰桌面的悬浮式交互 |
| **效率** | 全局快捷键一键唤起，语音/文字双模输入 |
| **智能** | ChatGPT 驱动的自然语言对话能力 |

## 2. 功能需求

### 2.1 功能全景

```
SiriAI for Windows
├── 桌面悬浮窗
│   ├── 液态玻璃气泡（idle 态）
│   ├── Dynamic Island 胶囊（激活态）
│   └── 展开对话面板（展开态）
├── 语音交互
│   ├── 唤醒词 / 全局快捷键唤起
│   ├── 实时语音识别（STT）
│   ├── Siri 风格波形动画
│   └── TTS 语音朗读
├── AI 对话
│   ├── ChatGPT 流式对话
│   ├── 上下文记忆（多轮对话）
│   ├── Markdown 渲染
│   └── 代码高亮
├── 系统集成
│   ├── 系统托盘驻留
│   ├── 开机自启
│   └── 全局快捷键
└── 设置
    ├── API Key 配置
    ├── 快捷键自定义
    ├── 外观主题（暗色/亮色）
    └── 语言设置
```

### 2.2 功能详述

#### 2.2.1 液态玻璃气泡（Idle 态）

- 一个约 120×120 px 的半透明气泡悬浮于桌面右上角
- 玻璃材质效果：
  - 背景模糊（实时采样桌面壁纸）
  - 菲涅尔边缘高光
  - 微弱的 RGB 色散（chromatic aberration）
  - 柔和的内发光
- 缓慢呼吸脉动动画（3-4 秒周期）
- 鼠标悬停时轻微跟随 + 放大（1.1x）
- 点击气泡进入 Dynamic Island 态
- 失焦 5 秒后自动缩回 Idle 态

#### 2.2.2 Dynamic Island 胶囊（Active 态）

- 气泡拉伸为水平胶囊形状（约 280×80 px）
- 平滑的 spring 动画过渡
- 胶囊内展示当前状态文案：
  - 🎤 "正在聆听…" + 波形条
  - ⏳ "思考中…" + 旋转指示器
  - 🔊 "正在回答…" + 声波动画
- 点击胶囊展开为完整对话面板

#### 2.2.3 展开对话面板（Expanded 态）

- 胶囊向下展开为一卡片面板（约 380×500 px）
- 面板顶部保留胶囊状态栏
- 面板内容区：对话消息列表
- 面板底部：输入栏（语音按钮 + 文字输入 + 发送按钮）
- 支持滚动查看历史消息
- 支持 Markdown 渲染、代码块高亮
- 点击面板外区域关闭

#### 2.2.4 Siri 波形动画

- 待机模式：气泡边缘柔和光晕呼吸
- 聆听模式：气泡表面随麦克风音量振动，底部浮现频谱粒子环
- 回答模式：气泡周围流动光带（类似 Siri 回答时的彩色波形）
- 波形数据来源：Web Audio API 实时麦克风分析

#### 2.2.5 ChatGPT 对话

- 支持 GPT-4o / GPT-4o-mini 模型
- SSE 流式响应，逐字打字输出
- 保留最近 20 轮对话上下文
- 对话历史本地持久化（localStorage）
- 支持新建对话 / 切换历史对话
- 错误重试机制（3 次）

#### 2.2.6 系统集成

- 系统托盘图标常驻
- 托盘右键菜单：显示/隐藏、设置、退出
- 全局快捷键 `Alt + Space`（可自定义）唤起/隐藏
- 开机自启选项

## 3. 交互状态机

```
                    ┌──────────────┐
         失焦超时    │              │  点击气泡
        ┌──────────│   IDLE       │──────────┐
        │          │  (液态气泡)   │          │
        │          └──────────────┘          │
        ▼                                    ▼
┌──────────────┐                    ┌──────────────┐
│              │   点击胶囊          │              │
│   HIDDEN     │◄──────────────────│  ACTIVE      │
│  (隐藏/托盘) │  关闭 / ESC       │ (Dynamic     │
│              │                    │  Island)     │
└──────────────┘                    └──────┬───────┘
        ▲                                  │
        │  全局快捷键                       │ 点击胶囊
        │                                  ▼
        │                         ┌──────────────┐
        └─────────────────────────│              │
                   关闭             │  EXPANDED    │
                                   │ (对话面板)    │
                                   └──────────────┘
```

**状态说明：**

| 状态 | 描述 | 视觉呈现 |
|------|------|----------|
| HIDDEN | 完全隐藏，仅托盘图标 | 不可见 |
| IDLE | 桌面悬浮气泡 | 液态玻璃气泡，呼吸动画 |
| ACTIVE | 聆听/思考/回答中 | Dynamic Island 胶囊 + 波形 |
| EXPANDED | 对话面板展开 | 胶囊 + 对话面板 |

## 4. 非功能需求

### 4.1 性能

| 指标 | 目标 |
|------|------|
| 空闲 CPU 占用 | < 2% |
| 3D 渲染帧率 | ≥ 60 FPS |
| 首屏加载 | < 1.5 秒 |
| 内存占用 | < 200 MB |
| 语音识别延迟 | < 500 ms |
| API 首次响应 | < 2 秒 |

### 4.2 兼容性

- 操作系统：Windows 11（主）、Windows 10 21H2+（兼容）
- GPU：支持 WebGL 2.0（不支持的设备降级为 CSS 纯毛玻璃模式）
- 麦克风：需要麦克风权限（语音功能）

### 4.3 安全性

- API Key 本地加密存储（AES-256）
- 对话数据仅存储在本地（localStorage），不上传第三方
- Electron `contextIsolation: true`，禁用 `nodeIntegration`

## 5. 视觉设计参考

### 5.1 参考来源

- iOS 27 Siri AI 官方宣传片
- Apple Human Interface Guidelines — Glass Material
- visionOS 玻璃材质参数

### 5.2 关键视觉参数

| 参数 | 值 |
|------|-----|
| 气泡基础圆角 | 60px（正圆） |
| 胶囊圆角 | 40px |
| 面板圆角 | 24px |
| 玻璃模糊度 | 30-40px backdrop blur |
| 玻璃透明度 | rgba(255,255,255,0.08) |
| 边缘高光 | rgba(255,255,255,0.3) 描边 |
| 暗色模式背景 | rgba(0,0,0,0.15) |
| 动画曲线 | cubic-bezier(0.25, 0.1, 0.25, 1) spring |

### 5.3 色彩方案

- 主色调：动态取色（从桌面壁纸提取）
- 亮色模式：白色基底 + 彩虹色边光
- 暗色模式：深灰基底 + 彩虹色边光
- 强调色：iOS 风格蓝 #007AFF

## 7. 成功指标

- 用户从唤起到获得回复全流程 < 5 秒
- 气泡 3D 渲染在集成显卡上稳定 60 FPS
